Inter - bundled variable fonts

Downloaded unchanged from Google Fonts v20 on 2026-10-26.
Source CSS: https://fonts.googleapis.com/css2?family=Inter:wght@100..900&display=swap
Upstream: https://github.com/rsms/inter
License: SIL Open Font License 1.1; see OFL.txt.

These normal variable WOFF2 files cover weights 100-900. The app registers
300-700, including the website's intermediate 450 weight. next/font/local
preloads Latin; subsets.css loads the remaining scripts only when needed.
The CSS family matches next/font/local's explicit Inter family declaration.
There are no runtime or build-time requests to Google Fonts.
